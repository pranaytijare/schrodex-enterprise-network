# schrodex-enterprise-network
Enterprise network design and implementation using Cisco Packet Tracer.

## Project Overview

Schrodex Technologies is a simulated enterprise networking project focused on designing, implementing and securing a multi-site enterprise network infrastructure.

## Project Objectives

- Design a structured enterprise network.
- Implement VLANs and inter-VLAN routing.
- Configure routing protocols and network services.
- Apply network security and access control.
- Perform connectivity testing and troubleshooting.

## Technologies & Tools

- Cisco Packet Tracer
- Cisco IOS CLI
- VLANs, Trunking and STP
- LACP EtherChannel
- OSPF
- DHCP and DNS
- NAT/PAT and ACLs
- SSH and Port Security

## Project Scope

Network topology design, device configuration, network segmentation, routing, centralized services, security implementation and troubleshooting.

## Repository Contents

Project files, network diagrams, configuration documentation, verification screenshots and testing results will be added as development progresses.
